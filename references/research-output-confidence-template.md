# Research Output Confidence Template

Use this template for any competitive-analysis / policy / market research deliverable where source credibility matters. Designed for the "multi-agent-research-cross-check" workflow.

## 1. Source Citation Rule

Every key claim must include:
- **URL** (exact, not site root)
- **Exact quote** from the page (in English if original is English, in Chinese if original is Chinese)
- **Access date** (YYYY-MM-DD)
- **Page type** (Official help center / Official policy / Press release / Third-party review / Forum user / etc.)

## 2. Confidence Levels

| Level | Meaning | When to Use |
|-------|---------|-------------|
| **High** | Directly confirmed by official source with clear text. | Use when the source explicitly states the fact. |
| **Medium** | Supported by official source, but missing execution details (e.g., cost, time boundary, regional variant). | Use when direction is clear but specifics are not. |
| **Low** | Only third-party / user-reported / indirect evidence. | Use when no official source exists but multiple users report similar experience. |
| **Speculative** | No direct evidence, or sources contradict each other. | Refuse to present as fact; label as speculation or open question. |

## 3. Conclusion Table Format

| # | Conclusion | Confidence | Source URL | Exact Quote | Notes / Gaps |
|---|------------|------------|------------|-------------|--------------|
| 1 | ... | High | ... | ... | ... |
| 2 | ... | Medium | ... | ... | ... |

## 4. Required Sections

1. **Confirmed Facts** (High confidence only)
2. **Directional Findings** (Medium confidence)
3. **Rumors / User Reports** (Low confidence)
4. **Open Questions / Contradictions** (Speculative)
5. **Methodology** (tools used, pages fetched, searches run, failed attempts)

## 5. What to Do When Evidence Is Missing

- If the user asks something not covered by any source: **state clearly that the answer is not available in the sources**.
- Do not fill in gaps with plausible-sounding guesses.
- If a logical inference is necessary, label it **Speculative** and explain the reasoning chain.
